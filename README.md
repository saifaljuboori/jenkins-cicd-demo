# Jenkins CI/CD Demo

A complete Jenkins CI/CD implementation demonstrating how a
GitHub-hosted application can be automatically tested, versioned,
containerized, published to Docker Hub, and integrated with
Jenkins Shared Libraries and GitHub Webhooks.

## Project progression

| Branch                    | Demonstrates                                    |
| ------------------------- | ----------------------------------------------- |
| 01-install-jenkins        | Jenkins on DigitalOcean                         |
| 02-jenkins-ci-pipeline    | Java/Maven CI pipeline                          |
| 03-jenkins-shared-library | Reusable Jenkins Pipeline logic                 |
| 04-dynamic-versioning     | Automated versioning and commit-loop prevention |
| 05-github-webhook         | Automatic CI triggering                         |

## Architecture

GitHub → Jenkins → Docker Hub → Deployment Server
